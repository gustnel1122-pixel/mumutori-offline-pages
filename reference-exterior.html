느슨한 외장재를 새 간판으로 가리는 것은 보수가 아닙니다.

전면의 들뜸·낙하 가능 범위를 전문가가 확인하고 안전하게 처리한 뒤, 건전한 구조체나 검증된 프레임에 고정하는 방식으로 설계합니다.

중앙 PALCIBO 문자는 타일 표면에 표시된 것처럼 보입니다. 별도 간판판넬인지 현장 확인이 필요합니다. 외장을 철거하면 기존 표시도 함께 사라질 수 있어, B안은 간판을 떼기만 하면 복원이 끝나는 구조라고 단정할 수 없습니다. 좌측 돌출 간판은 별도로 점검하고 처리 범위를 정합니다.

간판 재료는 ‘전체 시공’으로 비교

전기배선 공정이 줄어드는 비조명 탈착 패널을 우선 비교합니다. 갈바·알루미늄복합판 등 외부용 패널의 바람·휨·고정부·분리방식을 업체가 함께 설계해야 합니다. 소형 포맥스·아크릴 상품 가격을 면적에 곱한 금액은 대형 외부 간판 견적이 아닙니다. 포맥스·아크릴 보조사인/글자와 전체 구조는 구분해 견적받습니다.

실제 견적이나 공인 업계 표준단가가 아닙니다.

발주 전에 결정할 7가지

  1. 외벽 안전 범위 — 전면 들뜸·탈락, 바탕 상태, 보행자 보호 계획을 사진과 견적으로 확인.
  2. 실측 — 중앙·돌출 간판 크기, 기존 PALCIBO 표시 방식, 고정 가능한 바탕 확인.
  3. A/B 선택 — 같은 범위로 견적2건, 공사 일정·개장 지연 영향 비교 후 결정.
  4. 비용과 소유권 — 보수·철거·영구마감·간판·철수 각각 부담자, 승인 상한, 증빙 수취자 확정.
  5. 설치 권한과 절차 — 계약상 외벽/간판 권한과 관할 옥외광고물 신규·변경 절차 확인.
  6. 탈착 설계 — 안전한 바탕, 방풍 고정, 외부용 재료, 기존 표시 보호, 납기·VAT·장비 포함 견적 승인.
  7. 복원 기록 — 설치 전후·체결부 사진, 부품 보관, 해체 순서, 3개월 후 복원 견적 확정.
