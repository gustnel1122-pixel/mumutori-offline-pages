주소를 옮기기 전,
팝업 운영에 필요한 확인

기존 사업장을 유지하며 3개월 공간대여를 이용할 때의 행정·결제·지도 노출 실행 가이드.

확인일 2026.10.04 · 법령·플랫폼 공식 안내 기반 · 개별 계약 및 기관 심사 전

진행 순서확인된 사실결제 방법지도·광고실행 체크리스트출처

가장 적은 변경으로 진행하는 순서

  1. 공간 사용권 확인 — 소매판매·행사·간판 설치가 원계약에서 허용되는지 확인합니다.
  2. 세무 처리방식 확정 — 현장 관할 세무서에 임시사업장 해당성을 확인합니다. 해당하지 않으면 기존 본점을 유지하면서 별도 사업장 등록 등 가능한 절차를 확인합니다.
  3. 판매자 본인 명의의 결제 승인 — 실제 현장주소·운영기간을 단말/VAN사에 밝히고 승인받습니다.
  4. 공개 행사 안내 → 네이버 팝업스토어 → 당근 웹사이트 광고 — 실제 장소·기간을 표시하고 플랫폼 심사를 거칩니다.
공간대여 계약과 사업자등록은 서로 다른 판단입니다.

주소를 변경하지 않거나 3개월 사용권을 구매했다는 이유만으로 사업장 신고·임대인 동의·간판 설치 확인이 모두 면제되는 것은 아닙니다. 아래는 채택이 확정된 계약 구조가 아니라, 가장 단순한 합법적 경로를 확인하기 위한 순서입니다.

사실과 확인할 부분

항목공식 근거로 확인된 내용현장에서 확인할 것
공간 사용권민법 제629조는 임대인 동의 없는 임차권 양도·전대를 제한합니다. A1공간 제공자의 소유/임차 여부와 제3자 팝업·소매·간판 변경 허용 범위. 이미 허용된 범위라면 새 동의가 불필요할 수도 있으나, 계약 내용과 실제 사용방식으로 판단합니다.
기존 본점 유지사업장마다 사업 개시일부터 20일 이내 등록하는 것이 원칙이며, 직접판매 시설인 직매장도 사업장에 해당합니다. A2·A3본점의 ‘이전’과 추가 사업장 처리는 다릅니다. 실제 기존 본점을 유지하면서 추가 등록 또는 사업자단위과세 변경등록 가능 여부를 확인합니다.
임시사업장행사 장소에 개설하고 신고한 임시사업장은 기존 사업장에 포함됩니다. 개설·폐쇄 각각 10일 이내 신고. 설치기간 10일 이내만 개설신고 생략이 가능합니다. A4·A53개월이면 자동 승인되는 기준은 확인되지 않았습니다. 진열시설·영업일·판매방식·종료일을 설명하고 타당성을 확인받습니다. 법정 기한 전이라도 판매 전 확인을 권합니다.
결제 명의다른 가맹점 명의 사용·명의대여는 금지됩니다. A6상품을 직접 판매하는 사업자 명의로 결제·정산. 공간 운영자 단말로 대신 받는 단순 대행정산은 선택하지 않습니다. 정식 위탁판매는 별도 계약·세무 검토가 필요한 다른 구조입니다.
온라인 결제현장에서 재화를 직접 판매하기 위한 시설은 별도 사업장 판단 대상입니다. A3주문QR·계좌이체만 사용한다고 현장 사업장 의무가 없어지는 것은 아닙니다.

결제는 기존 장비 활용부터

우선순위방법실행·비용 확인
1순위본인 가맹점 + 기존 장비 현장 사용기존 가맹점/단말 보유 확인 → 실제 현장주소·기간 승인. 단말기 이동만으로 승인되는 것은 아닙니다.
2순위본인 명의 단기 렌탈 + 모바일 POS설치·회수·통신·관리·해지·VAT를 합친 3개월 총액 견적. 토스는 실제 팝업 활용 사례와 단기 렌탈 비교를 안내하지만 고정 정가가 공개된 것은 아닙니다. A7·A13
보조본인 스마트스토어 주문QR + 방문수령실제 상품·재고·현장수령·취소 안내를 갖춥니다. 공식 방문수령 처리 경로가 있으나 고객 주문 마찰, 수수료, 정산 지연을 고려합니다. A14
비상용계좌이체 + 현금영수증매출로 기록하고 현금영수증 발급 요건을 준수합니다. 카드가맹점은 카드 사용을 이유로 거절·불리한 대우를 하거나 수수료를 전가할 수 없습니다. A18

단말/VAN사에 확인할 문장

기존 사업자번호로 [정확한 주소]에서 [시작일~종료일] 동안 팝업 판매를 합니다. 세무 처리는 [확정된 처리방식]입니다. 본인 명의 가맹점으로 현장 결제가 가능한지, 기존 단말 이동 또는 행사 단말의 심사·필요서류를 알려주세요. 3개월 총액에 설치·회수·통신·관리·해지비와 부가세가 포함되는지, 영수증 표시정보와 정산계좌도 확인 부탁드립니다.

네이버와 당근은 이렇게 시작

네이버: 실제 행사라면 ‘팝업스토어’로 신청

공식 안내에 팝업스토어 업종과 운영기간 입력 경로가 있습니다. 행사명·정확한 장소·기간·영업시간·판매내용·문의처가 담긴 공개 안내페이지, 간판/현장 사진 또는 브랜드 행사공문으로 심사를 준비합니다. 단순 기획안·계약서만으로는 불가할 수 있습니다. 기존 장소의 플레이스 링크를 연결할 수 있습니다. A8·A9

네이버의 팝업 등록 승인과 세무상 임시사업장 인정은 서로 다른 절차입니다.

당근: 공개 행사페이지로 연결하는 웹사이트 광고

비즈프로필은 사업자 정보와 상호·주소·업종이 다르면 반려될 수 있어 팝업 주소증빙은 별도 확인합니다. 초기에는 실제 사업자 정보로 광고계정을 만들고 웹사이트 방문 캠페인에 공개 행사 URL과 현장 인근 지역을 지정하는 경로를 우선 검토합니다. 기간·한도를 정하고 심사 승인 후 집행합니다. A10~A12

광고 연결 페이지는 정상 작동하는 HTTPS 페이지로, 광고한 행사를 바로 확인할 수 있어야 합니다. 내부 예산·공동편집 링크를 고객용 광고에 연결하지 않습니다. A15

실행 체크리스트

  1. 사용권 — 정확한 주소·층·면적과 원계약의 공간대여·소매·간판 허용범위를 문서로 확인.
  2. 이용계약 — 시작/종료일, 실제 대여료·VAT·관리비, 허용업종, 집기 소유권, 보수 책임, 간판·원상복구·조기종료·연장을 명시.
  3. 세무 질의 — 임시사업장 해당 여부와 미해당 시 추가 등록 경로 확인. 답변일·담당·접수번호 기록. 단순 상담을 최종 승인으로 표시하지 않기.
  4. 신고 접수 — 채택한 방식의 접수증·통지 보관. 임시사업장은 개설일부터10일 이내, 일반 추가 사업장 등록은 원칙적으로 개시일부터20일 이내.
  5. 현장 결제 — 판매자 명의·현장주소 사용승인, 3개월 총비용, 카드·간편결제·현금영수증·취소·정산 시험.
  6. 공개 행사 증빙 — 행사 안내·현장사진 준비 → 네이버 팝업스토어 신청 → 승인 확인.
  7. 지역 광고 — 공개 URL·지역·기간·한도 설정 → 심사 승인 → 집행 결과 기록.
  8. 종료 준비 — 간판·집기 회수, 원상복구, 고객·플랫폼 안내, 필요 시 임시사업장 폐쇄일부터10일 이내 신고.

세무서 문의용 문장

기존 사업장을 유지하면서 [현장주소]를 [시작일]부터 [종료일]까지 이용해 소품과 서비스를 직접 판매하려고 합니다. 진열집기를 설치하고 [영업일/영업시간] 운영합니다. 실제 운영형태가 부가가치세법 제6조 및 시행령 제10조의 임시사업장에 해당하는지, 해당하지 않으면 기존 본점을 유지하면서 추가 사업장 등록 또는 사업자단위과세 변경등록을 어떻게 처리할지 확인 부탁드립니다. 사용권 증빙·업종·필요서류도 안내 부탁드립니다.
