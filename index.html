메인 매장만 작게 · 버터 집기 설치 확인 · 11/1(일) 오픈
사용자 확정
  • 후면 계단 아래 카운터와 그곳의 기존 집기 유지
  • 중앙 테이블과 벽면 진열 집기를 모두 버터 집기로 교체
  • 상판과 하단은 동일한 사각형, 한눈에 보이는 버터 덩어리
  • 아래 은색 포장지, 위로 올라온 버터가 흘러내리다 굳은 모습
  • 기존 벽면 우드·조명 유지, 상단 흰 벽에 버터 드립 도장
  • 별도 벽면 한쪽에 타자기·레터 작성 공간, 바로 옆 우편함 — 이전 안(10/11 변경)
  • 작성·투입·결제 후 다음날 전량 집계·타자기 인쇄·우편 발송 — 이전 안, 레터서비스는 온라인으로
  • 홍대·연남동 소품상점 분위기의 간판과 입구 스탠드 배너
  • 10/11 메인 매장만 작게 운영 — 안쪽은 온라인 전용 재고창고·작업실(직원만), 매장 레터 코너·우편함·외부 포토존 없음
  • 10/11 가운데 버터 테이블은 기존 테이블만큼 크게(약 200×60cm), 제작 방식은 견적 후 결정
  • 10/11 버터 집기 설치 목표 10/27 · 전체 오픈 목표 10/31
이번 시안의 제안
  • 중앙은 낮은 상품 진열로 버터 블록과 포장지의 실루엣 강조
  • 은색 접힘 마감에 크림색 종이 가장자리와 작은 도토리 포인트
  • 레터 코너는 옆 벽의 버터 콘솔, 우편함은 손이 닿는 인접 위치 — 이전 안
  • 정면·돌출간판·배너의 글자 기준선, 자간, 여백을 하나로 정돈
  • 원고·고객 보관표·결제를 접수번호로 대조하는 방식 검토 — 이전 안
  • 오른쪽 벽은 거울과 키링 행거, 창가에는 모듈 테이블 2개
제작 재료·예산·상품 구색은 미확정입니다. 레터 규격·가격은 온라인 레터서비스에서 정합니다.
건물주 사용 동의 요청은 기존 임차인 담당입니다. 무무토리 사업자 주소는 그대로 두고 공간을 3개월 팝업으로 이용하는 방향입니다.


INTERACTIVE SPACE / 3D
돌려 보고, 놓아 보는 무무토리.
2026.10.11 수정 · 메인 매장만 작게 운영
후면 계단과 기존 카운터는 유지합니다. 은색 포장지 위 버터 집기에 실제 판매했던 소품을 놓고, 오른쪽 벽은 거울과 키링 행거, 창가에는 모듈 테이블 2개를 둡니다. 뒤 통로 안쪽은 온라인 전용 재고창고·작업실(직원만)이며, 매장 레터 코너·우편함과 외부 포토존은 두지 않습니다.
회전·확대로 진열과 동선을 살펴보세요. 제품 사진은 첨부한 기존 레퍼런스에서 가져왔으며, 집기·공간 비례는 실측 전 제안입니다.
02 / BEFORE & AFTER
같은 공간, 새로운 장면.
Drive ‘팔시보 스토어’ 사진 9장 확인
2026.10.03 기준 · 실측 전
실제 사진과 생성 이미지를 나란히 봅니다. 전면 유리·왼쪽 출입문·벽면 우드·기존 조명·후면 계단을 기준으로 제작했습니다. 생성 과정에서 세부 형태가 달라질 수 있으며, 3D 이미지는 사진으로 추정한 공간 관계를 보여 줍니다. 치수 도면이나 편집 가능한 3D 모델은 아닙니다.

  • 거리에서 볼 때 왼쪽 출입문과 넓은 전면 유리
  • 높게 올라오는 우드 패널과 좁은 상단 흰 벽
  • 흰 레일 조명·천장형 냉난방기·노출 배관
  • 후면 계단 하부의 기존 우드 카운터
  • 측면 개구부, 기존 금속 진열대
